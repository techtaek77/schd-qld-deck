# SCHD 비빔밥에 QLD 고추장, 몇 숟갈이 제일 맛있었을까

SCHD와 QLD를 10%p씩 섞은 11가지 비율을 2011-10-20 ~ 2026-10-12 실제 데이터로 백테스트한 17장 HTML 슬라이드. 16장 근거표는 시작점을 2007·2000년으로 바꿔 같은 비교를 다시 돌린 결과다.

- 보기: https://techtaek77.github.io/schd-qld-deck/ (←/→ 이동, N 강사 멘트, T 테마, 6장 슬라이더, 5장 비율 막대 차트, 12장 배당 재투자 vs 인출, 16장 근거표)
- 블로그: https://www.dividend-nomad.com

가정: USD 기준, 배당 85% 재투자(미국 원천징수 15%), 매년 첫 거래일 리밸런싱, 환율·국내 세금·거래 비용 제외. 데이터: Yahoo Finance 일별 종가·분배금(SCHD, QLD, QQQ, DVY, DIA). 2006년 이전 QLD는 QQQ 일간 2배 합성, 비용은 실제 QLD 2011~ 연평균에 맞춰 연 2.8%로 보정. 과거 데이터 비교이며 투자 권유가 아니다.
